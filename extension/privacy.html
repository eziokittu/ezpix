EzPIX Insta privacy

Updated 30 October 2026.

EzPIX Insta processes images, captures, videos and palettes locally in your browser. The extension has no account, advertising, analytics, image upload or remote processing service. All executable code ships inside the extension.

What you choose to open

Page capture starts only after your toolbar action and captures visible pixels. Camera and screen sharing start through the browser permission chooser. Streams stop after capturing a frame, pressing Stop or closing the panel. Colour picking samples only the opened source image.

Local retention

Captured pixels, selection state and temporary transfers can remain in extension IndexedDB for up to ten minutes. Expired records are removed when the extension wakes. Clear capture & pending handoff removes those records and resets conversion. Downloads are independent files under your control. Appearance preferences remain in local browser storage. No artwork is stored in Chrome Sync.

Older versions offered opt-in manual-studio recovery. Existing drafts can remain in this browser profile under their earlier four-draft, 8 MiB, seven-day limits; expiry cleanup runs when the extension wakes. This version does not create new manual-studio drafts. Remove extension site data to delete legacy drafts immediately. Keep downloaded files as backups.

Optional website editor

Capture, conversion and downloads work without opening a website. Only when you choose Open in Pixel studio does the extension make converted artwork available to https://glitchbong.com/tools/ezpix through a temporary, tab-bound local browser message bridge. Original input images are omitted. The editor requires explicit Receive and Import actions before replacing artwork. Artwork is not uploaded to a server by this handoff. The website has its own privacy policy for ordinary website traffic.

Limited Use

EzPIX Insta uses information received from Google APIs only for the requested capture and conversion features, adhering to the Chrome Web Store User Data Policy, including Limited Use requirements. Artwork is not sold, used for advertising or sent to the developer or third parties.

Permissions

activeTab permits explicitly requested visible-page capture. scripting installs the temporary capture selector and checks page geometry. alarms expires local records. sidePanel displays the conversion controls beside the page. There is no blanket host, clipboard or browsing-history permission. The GlitchBong website can discover the matching extension and receive only an explicitly prepared, token-bound transfer.
