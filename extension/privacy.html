EzPIX Insta privacy

Updated 1 November 2026.

EzPIX Insta processes images, captures, videos and palettes locally in your browser. The extension has no account, advertising, analytics, image upload or remote processing service. All executable code ships inside the extension.

What you choose to open

Each fresh toolbar click automatically captures the entire visible page; area and element captures use their explicit buttons. Protected pages may refuse capture. Camera and screen sharing open a temporary local extension capture tab so Chrome can show its permission chooser. Audio is never requested. Streams stop after capturing a frame, pressing Stop, closing the capture tab or the ten-minute capture session expiring. Colour picking samples only the opened source image.

Local retention

Opened media, captured pixels, selection state and temporary transfers can remain in extension IndexedDB for up to ten minutes. Expired records are removed when the extension wakes. RESET asks for confirmation before removing those records, resetting conversion settings and closing any local camera/screen capture tabs. Downloads are independent files under your control. Appearance preferences remain in local browser storage. No artwork is stored in Chrome Sync. The capture selector and camera/screen capture tab temporarily bind the chosen source tab and window, a random return token and ten-minute expiry. The toolbar popup creates no additional browser window. A one-use return record binds a source tab/window for at most thirty seconds so returning from area/element selection or camera/screen capture restores that result instead of recapturing. Each fresh toolbar click starts a new visible-page capture. Download finished edits before dismissing the popup.

Older versions offered opt-in manual-studio recovery. Existing drafts can remain in this browser profile under their earlier four-draft, 8 MiB, seven-day limits; expiry cleanup runs when the extension wakes. This version does not create new manual-studio drafts. Remove extension site data to delete legacy drafts immediately. Keep downloaded files as backups.

Optional website editor

Capture, conversion and downloads work without opening a website. Only when you choose Open in Pixel studio does the extension make converted artwork available to https://glitchbong.com/tools/ezpix through a temporary, tab-bound local browser message bridge. Original input images are omitted. Choosing Open in Pixel studio authorizes the editor to receive, validate and open that preview automatically. Replacing unsaved artwork still asks for confirmation. Declining keeps your current artwork and the pending transfer. The extension removes a transfer only after the editor acknowledges a successful import. Artwork is not uploaded to a server by this handoff. The website has its own privacy policy for ordinary website traffic.

Limited Use

EzPIX Insta uses information received from Google APIs only for the requested capture and conversion features, adhering to the Chrome Web Store User Data Policy, including Limited Use requirements. Artwork is not sold, used for advertising or sent to the developer or third parties.

Permissions

activeTab permits explicitly requested visible-page capture. scripting installs the temporary capture selector and checks page geometry. alarms expires local records. There is no blanket host, clipboard or browsing-history permission. The GlitchBong EzPix pages can check whether the extension is available and, when you click EzPIX Insta, open its normal toolbar popup. This records the initiating tab/window for at most ten seconds; the one-use record is consumed on opening or removed on expiry/RESET. Opening from the website does not grant page-capture permission. Without a prior toolbar grant, the popup offers local media, camera and screen sharing; click the pinned toolbar icon for page capture. Discovery and opening reveal availability and version, never artwork. Artwork is shared only through an explicitly prepared, token-bound transfer.
