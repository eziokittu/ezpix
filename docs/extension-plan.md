# EzPIX Insta extension architecture

2 November 2026. Extension and shared engine/vendor **0.466.2**. Shared algorithms in packages/core; website consumes a versioned archive. See [current handoff](../../glitchbong/docs/ezpix-release-local.md) and [core contracts](../packages/core/README.md).

## Website launcher (local update, not pushed)

The website retires its Focus studio converter and uses one EzPIX Insta action in the dense and tiled headers and extension/help pages. If the configured extension is not detected, the action opens the existing store listing in a new tab without navigating away from artwork. Discovery exposes the openPopup capability and extension version. Older installs link to their store update; denied/failed opens explain the pinned-icon fallback. Availability is checked on mount, focus and return from installation. Local QA uses NEXT_PUBLIC_EZPIX_EXTENSION_ID for the unpacked development ID; production defaults to the published ID.

External open-popup requests use Chrome action.openPopup, never a new studio tab/window. Exact origin, allowed path, top frame, active document and the focused normal window/active tab are required. A one-use tab/window record expires after ten seconds and clears on RESET. Discovery never opens UI or exposes pixels. Opening programmatically does not grant activeTab: without an existing grant, show the compact local-media chooser with toolbar-capture guidance; with a grant, capture normally. Actual toolbar clicks and selection/media workflow returns retain their existing behavior. No permissions or shared-core changes.

## Capture and conversion popup

Chrome MV3, minimum Chrome 127. The action.default_popup entry opens app.html in the normal toolbar popup and grants activeTab. It uses the same anchored popup mechanism as Table Grabber. The toolbar popup provides visible-page, region and element capture, image/video files, camera/screen chooser, full-image default conversion, optional selection and background removal. All processing and downloads run locally. The fixed viewport reserves the right column for one expanded settings section. Manual editing is provided by the website; retired popup/manual editor files are excluded from the release.

The selector supports Escape and removes its overlay before capture. Background checks the initiating active tab/document, viewport/scroll/DPR before and after screenshot capture, and crops using actual image dimensions. Navigation, protected pages, moved/closed tabs and changed geometry reject. Visible screenshots cap at 16 megapixels; retained crops at four. Captures are saved with ten-minute expiry, then CAPTURE_READY refreshes an open popup. The selector closes the popup to receive page input. Capture or Escape reopens it with chrome.action.openPopup, which requires Chrome 127. Fresh toolbar clicks capture the entire visible page. A one-use workflow return restores selected/camera results without recapturing.

New sources select the full rectangle and keep background. Shape selections remain optional; Select entire image restores the full rectangle. Colour removal samples raw source RGB, never the processed preview. A circular nearest-neighbour magnifier and keyboard arrows/Enter/Escape support exact sampling. Tolerance is 0-255 per-channel distance; soft edges fade the next 0-128 steps. Border-connected removal is also available. No semantic segmentation or AI is implied. Matching colours inside an object may be removed; inspect the preview.

Output fits 256px axes. Video input caps at eight seconds, 32 MiB and 32 sampled frames; working video frames resize to 512px. Camera/screen streams run in a dedicated local capture tab and stop after frame capture, Stop, tab closure or session expiry. Jobs reject stale responses. Downloads exclude source images. Capture files, user names, URLs and palettes never enter logs/telemetry.

## Permissions and retention

Exactly activeTab (explicit page capture), scripting (selector/geometry) and alarms (expiry). The action popup requires no additional permission. No blanket host, clipboard, storage/sync or browsing-history permission. IndexedDB stores the last opened media, capture, selection and transfer records for ten minutes. Camera stills are PNG; supported local media files retain their original bounded input for a workflow return. Fresh toolbar clicks replace the preview with the current page capture; download finished edits before dismissal. Legacy opt-in manual recovery drafts retain their earlier seven-day/four-draft/8 MiB expiry cleanup; this version creates no new manual drafts. Appearance is localStorage. The bundled and website-source privacy pages describe these policies and the website launcher. The previously deployed privacy/help came from master commit 2d6c503; the new launcher disclosure remains local until a separately authorized deployment.

## Toolbar popup layout

Empty mode is 420x280; media mode is 780x580. Short displays reduce the requested height and width. Chrome can clamp the viewport further; the body fits its actual viewport. Clearing media shrinks back to the chooser. No windows.create, windows.update, sidePanel or separate studio tab is used. The cyan/blue top, preview, settings and export sections have explicit borders and 10-12px gutters. Source and output stack on the left; each header is a keyboard-accessible collapse button, with the other preview filling available space and at least one preview kept visible. Opening Selection or the source colour picker reveals the source. Settings scroll on the right, with compact Selection rows. Exports span both columns, with matching Save as colours and an external-link icon on Open in Pixel studio. Cancel preview is removed. One red RESET confirms before clearing current media, restoring default conversion controls and deleting pending handoff/capture/session records. Cancelling RESET preserves the current export. One accordion section always stays open. Canvas display sizes preserve actual aspect ratio for accurate sampling and selection.

START carries the active tab/window resolved in the popup's currentWindow, and background rechecks that exact tab is active in that window. A background lastFocusedWindow query can resolve to the popup itself and is deliberately avoided. The selector then binds nonce, top frame and document identity, preserving existing geometry checks. Returning the popup does not focus another browser window. A popup already open is refreshed without replacing its document.

## Camera and screen capture

MEDIA_OPEN is accepted only from the packaged popup and binds a created local media.html tab to the current return tab/window, random 256-bit nonce and ten-minute expiry. MEDIA_INIT/COMPLETE/CANCEL require the exact extension ID/page, top frame and live runtime document identity for that tab. Completion/cancellation also require the nonce. The PNG data URL is bounded to 24 MiB, checks PNG signature/dimensions (four megapixels), and decodes before commit. One IndexedDB transaction verifies the current nonce/expiry before saving a photo and deleting its session, so stale completion after RESET is rejected. The capture tab closes and the normal popup returns only when appropriate to the current tab/window. No audio, extra manifest permission, upload, offscreen document or background recording is used.

The capture tab shows red errors distinguishing Chrome/Windows access blocks, missing/busy devices and screen chooser cancellation. Permission is requested by its Enable camera or Choose screen button, outside the transient toolbar popup. Both stream termination and expiry are enforced locally. Physical-device and native-chooser qualification remain separate from simulated browser tests.

## Expanded workspace and persistent selection masks in 0.466.0

Both image surfaces have a bottom-left expand button. A modal workspace covers the popup toolbar, retains the original canvas elements/handlers and live controls, and provides Input/Output switching, a close button, Escape dismissal and normal dialog focus confinement. Active preview intrinsic width > height places settings underneath; portrait and equal axes place them on the right. Resizing and changing dimensions refit the image without stretching. Closing returns canvases/settings/status to their exact original homes. No new tab/window, screen permission or browser fullscreen permission is used.

Selections now have explicit per-pixel membership. Lasso uses coalesced pointer samples (up to 8,192 points) and an even-odd scanline fill instead of repeatedly reducing the outline to 128 points. Commit enables Focus object and supplies the compact crop-relative mask to the worker. Rectangle, ellipse, polygon, freehand and brush all support Replace/Add/Remove. Magic uses a four-connected flood with maximum per-channel RGB distance from the clicked seed (0-255, default 64), ignores transparent pixels and never drifts through a gradual colour ramp. Tolerance recomputes only the last magic region against its saved pre-click selection. Other colours require additive clicks or manual refinement. This cannot infer the semantic boundaries of every car or separate foreground/background with identical touching colours.

Masks apply before tone/blur/palette/grid operations; motion tracking translates the same crop-relative mask. One selection Undo retains the previous edit. An empty selection clears the output and disables export; cancellation restores the last completed selection. Nonmembers are transparent black. A checkerboard makes output transparency visible. Source sampling remains based on original pixels; selection shading is cached separately. Selection masks are transient, not a new project or wire schema. Image budgets remain four megapixels, with a 32-million polygon scan budget and bounded point count. No permissions, privacy retention, capture, transfer trust or schema changes.

The engine/package version advances together; matching website vendor/lock/provenance are synced locally. The website must be published with that engine before the updated extension can hand off to it. No push/deployment/store upload is authorized or performed by this work. See expanded-selection.md for local checks and package paths.
